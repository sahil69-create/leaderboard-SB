# Donation payments setup

The leaderboard donation flow uses Razorpay for checkout and Supabase for verified donor records.

## Vercel environment variables

Add these variables to the separate leaderboard Vercel project:

- `RAZORPAY_KEY_ID`: Razorpay test or live key ID
- `RAZORPAY_KEY_SECRET`: Razorpay secret, server-side only
- `SUPABASE_URL`: Supabase project URL
- `SUPABASE_SERVICE_ROLE_KEY`: Supabase service-role key, server-side only
- `SUPABASE_DONATIONS_TABLE`: optional; defaults to `donations`

Use Razorpay test keys first. Switch both key ID and secret together when going live.

## Supabase table

Run this SQL in Supabase SQL Editor:

```sql
create table public.donations (
  id bigint generated by default as identity primary key,
  donor_name text not null,
  donor_email text not null,
  donor_phone text not null,
  payment_id text not null unique,
  order_id text not null,
  amount integer not null check (amount > 0),
  source_website text not null,
  source_page text not null,
  paid_at timestamptz not null default now()
);

alter table public.donations enable row level security;
```

The API uses the service-role key, so no public insert or select policy is needed. Never expose that key in browser JavaScript.

After adding the variables, redeploy the `leaderboard-SB-main` project. Verified donations will show the donor name, amount, payment time, and source website in the leaderboard.
